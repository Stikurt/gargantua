# Пилот каталога метаданных

`catalog-discovery.py` использует Python 3.10+ и стандартную библиотеку. Он обращается только к JSON API `https://openlibrary.org`: поиск, карточка автора и список его произведений. Тексты, архивы и обложки не скачиваются. Сервер, БД и контейнеры не изменяются.

```powershell
python scripts/catalog-discovery.py --help

# Сначала различить людей с похожими именами; результат содержит ID, даты и известную работу.
python scripts/catalog-discovery.py author "Arthur C. Clarke" --output .local/catalog/clarke-candidates

# Только после выбора личности: каталог связанного с ней авторства, включая соавторство.
python scripts/catalog-discovery.py author "Arthur C. Clarke" --author-id OL2623461A --limit 60 --sort publication --output .local/catalog/clarke

# Официальный порядок первого цикла; сопоставление с найденными Work остаётся кандидатным.
python scripts/catalog-discovery.py series "Warriors" --alias "Коты-воители" --curated-order docs/gargantua/examples/catalogs/warriors-first-arc-order.json --output .local/catalog/warriors

# Произвольная серия без редакционного списка: кандидаты, порядок чтения неизвестен.
python scripts/catalog-discovery.py series "Rama" --author-id OL2623461A --output .local/catalog/rama-series

python scripts/catalog-discovery.py search "Rendezvous with Rama" --output .local/catalog/rama-title

# Повторить ровно тот же запрос по кешу без сети; меняется только путь результата.
python scripts/catalog-discovery.py author "Arthur C. Clarke" --offline --output .local/catalog/cached-clarke-candidates

python -m unittest discover -s tests -p test_catalog_discovery.py -v
```

Если `python` на Windows открывает Microsoft Store, используйте установленный интерпретатор или [PowerShell-обёртку](catalog.ps1): `./scripts/catalog.ps1 --help`. Она передаёт те же аргументы, сначала ищет готовый runtime этого ПК, затем `py -3`/настоящий Python. Например: `./scripts/catalog.ps1 author "Arthur C. Clarke" --output .local/catalog/clarke-candidates`. Python не устанавливается этим инструментом автоматически.

В явно выбранном `--output` создаются `catalog.json`, `catalog.html` и `catalog.md`. HTML открывается локально без сервера и скриптов, содержит список кандидатов, порядок из seed, найденные произведения, охват, ограничения и даты источников. Для существующих файлов требуется `--overwrite`. Одновременный экспорт в тот же каталог блокируется. При аварийном завершении может остаться `.catalog-export.lock`; выберите новый каталог либо убедитесь, что экспорт не работает, прежде чем вручную убирать эту собственную блокировку. Три файла заменяются по одному: это не транзакционный формат основной библиотеки; успешный код завершения означает окончание всех трёх записей.

Идентичность автора не определяется первым результатом. Автоматически принимается только единственная запись во всей выдаче с точным нормализованным именем/алиасом. При неоднозначности сохраняется `needs-clarification`; повторите команду с выбранным `--author-id`. Кандидаты и результат поиска не доказывают фактическое авторство или полноту библиографии; явный ID тоже требует осмысленного выбора человеком.

Для серии поиск по названию/subject не объявляет каждое совпадение членом серии. `seriesEvidence` хранит проверяемые сигналы, `seriesMembership` остаётся кандидатным. Переданный локальный `--curated-order` использует `schemaVersion: 1`, `orderType`, `scope`, массив `evidence` с HTTPS URL/датой и `items` с собственным `curated:` ID, `sequence`, `title`, `author`, необязательными `searchAliases`. Начальный предел — 50 записей, удобнее передавать отдельный цикл. Совпадение названия и автора присоединяет **все** подходящие Work ID как кандидатов; роман, адаптация и сборник не объединяются. Не найденный том остаётся в порядке как `unresolved`.

`--sort publication` сортирует только полученную ограниченную выборку по указанному в метаданных первому году. Это не рекомендуемый порядок и не внутренняя хронология. Отсутствующие/неоднозначные даты остаются неизвестными. Без seed `readingOrder.kind` равен `unknown`. Список первого цикла «Котов-воителей» не называется полным перечнем франшизы.

Ограничения сети: не чаще одного запроса в 1,05 секунды в одном процессе; до трёх попыток, общий бюджет `--max-requests` включает повторы; максимум 25 запросов за запуск. Не запускайте несколько копий одновременно для обхода ограничения источника. `Retry-After` соблюдается; длительное ожидание прекращает запуск с просьбой повторить позже. По умолчанию socket timeout 15 секунд, на медленном источнике можно задать `--timeout 20`. Есть deadline чтения ответа и лимит 8 MiB; DNS и системные сетевые операции остаются зависимыми от ОС. Редиректы и произвольные хосты/endpoint запрещены. Настройка proxy из окружения не используется.

Кеш по умолчанию `.local/catalog-discovery-cache`, TTL 24 часа, максимум 128 собственных hash-JSON файлов и 64 MiB. По достижении предела новый ответ не кешируется, выводится предупреждение, существующие файлы не удаляются. `--offline` может использовать старый кеш с отметкой `stale`; это не свежая проверка доступности. Пагинация ограничена количеством записей/страниц/запросов, дубли удаляются только по Work ID. Частичная выдача сохраняется с причиной и ненулевым кодом завершения. «Все страницы получены» не означает полную авторскую библиографию.

Коды завершения: `0` — отчёт сохранён, в том числе с необходимостью уточнения или без совпадений; `1` — сетевая/источниковая ошибка либо частичный результат; `2` — неверный ввод, занятый/существующий output или ошибка файловой записи. Ошибка до получения первой страницы может завершить запуск без отчёта. Скрипт не является серверным publisher, антивирусом, загрузчиком книг или универсальным парсером сайтов.

Официальные основания интерфейса и ограничений: [Open Library APIs и правила](https://openlibrary.org/developers/api), [Search API](https://openlibrary.org/dev/docs/api/search), [Authors API](https://openlibrary.org/dev/docs/api/authors), [синтаксис поиска](https://openlibrary.org/search/howto). Метаданные проверялись 22 октября 2026 года; схема внешнего сервиса может меняться.
