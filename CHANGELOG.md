# История изменений

## v0.9.0 — 24 октября 2026

Готовые файлы предусмотрены на странице [v0.9.0](https://github.com/Stikurt/gargantua/releases/tag/v0.9.0): [Android APK](https://github.com/Stikurt/gargantua/releases/download/v0.9.0/Gargantua-Android-0.9.0.apk) и [Windows x64 ZIP](https://github.com/Stikurt/gargantua/releases/download/v0.9.0/Gargantua-Windows-0.9.0-x64.zip). Ссылки открываются после публикации выпуска. Windows ZIP распаковывается целиком; это portable-приложение без отдельного установщика.

Windows и Android получили общую чистую библиотеку с вкладками «Все книги» и «Каталоги», поиском по словам названия и автора, общим выбором книг и отдельным режимом порядка. Каталоги хранят ссылки без дублирования книг; перемещение из текущего каталога сохраняет связи с другими.

Android получил отдельную foreground-службу скачивания, устойчивые тексты и очередь, сохранение намеренной паузы и ограничений источника. На главном экране телефона подтверждён фактический прирост сохранённых глав; постоянная работа на всех устройствах и автозапуск после перезагрузки не обещаются.

Каталог Android можно сохранить одним файлом `Название.gargantua.zip`, передать через системное меню и импортировать с проверкой структуры и SHA-256. Сохраняются включённые главы и ручной порядок; личные позиции, закладки и адрес сервера не передаются. Повторный импорт использует прежние книги; несовместимые тексты не перезаписываются. Windows-импорт файла не реализован.

Проверены настоящий Windows EXE **52/52**, библиотека физического Android **66/66** и окончательный APK с именованным вложением **184/184**. JavaScript — **151 тест** отдельными командами, Java — **45**, lint — **0 ошибок / 13 предупреждений**. Происхождение сборок и границы офлайн-проверок указаны в [отчёте](docs/gargantua/ANDROID_MVP_0_9_ACCEPTANCE.md).

Сервер остаётся **0.7.1** и нужен для поиска и новых загрузок; сохранённые тексты читаются автономно. Озвучка не изменялась и остаётся в `experimental/audio`. Бинарные файлы привязаны к своему выпуску, а исторические отчёты сборки исходников сохраняют состояние на дату проверки.

## v0.8.0 — предыдущий опубликованный выпуск

Android 0.8.0, Windows и сервер 0.7.1: поиск русскоязычных книг и новелл в семи источниках, объединённые оглавления, очередь целой книги, закладки и чтение сохранённого текста. Проверены USB и приватный HTTPS Tailscale. Исторические проверки сохранены отдельно в [методике](docs/TESTING.md).
