# Гаргантюа

Клиент для поиска и чтения книг и новелл на Windows и Android. Текущие исходники `main`: **Windows и Android 0.9.0**, книжный сервер **0.7.1**. Озвучка находится в отдельной ветке [`experimental/audio`](https://github.com/Stikurt/gargantua/tree/experimental/audio).

Сервер ищет в семи каталогах, получает оглавления и текст. Клиент хранит библиотеку, скачанные главы, очередь загрузки и закладки на своём устройстве. После скачивания читать можно без сервера и интернета.

## Возможности

- Поиск по русскому названию, включая «Король в жёлтом» / «Король в желтом» и книги серии «Коты-воители».
- ЛибКат, ЛитЛайф, Викитека, Project Gutenberg, RanobeLib, Ranobe.me и RanobeHub.
- Поиск других изданий и продолжений, предпросмотр объединённого оглавления с указанием источника каждого раздела.
- «Скачать целиком», видимый прогресс, пауза, продолжение после перезапуска и сохранение уже скачанного текста.
- Общая витрина **«Все книги»** и отдельные **«Каталоги»**; поиск в своей библиотеке по словам названия и автора, независимо от порядка слов и `ё/е`.
- Каталоги хранят ссылки на книги: повторное добавление не создаёт копий, у каждого каталога собственный ручной порядок. Перемещение из текущего каталога сохраняет остальные связи.
- Возвращение к книге, главе и положению прокрутки, именованные закладки, размер текста и тема чтения.
- Android: отдельная служба фоновой загрузки с уведомлением и сохранением прогресса, подключение к своему серверу через USB или приватный HTTPS Tailscale.
- Android: сохранение каталога одним файлом `Название.gargantua.zip`, системное меню отправки и импорт с проверкой контрольных сумм. Включённые в файл главы читаются без сервера.

Сайты могут ограничивать доступ или менять разметку. Частичная загрузка честно остаётся частичной. [Известные ограничения](docs/LIMITATIONS.md).

## Готовые приложения

Сейчас опубликованы обновлённые **исходники 0.9.0**. Готового GitHub Release 0.9 пока нет: приложения собираются по инструкции ниже.

[Предыдущий выпуск v0.8.0](https://github.com/Stikurt/gargantua/releases/tag/v0.8.0) содержит прежние Windows x64 ZIP и Android APK с SHA-256. Эти файлы не обновляются при изменении `main` и не содержат новых возможностей 0.9. Для Windows всегда распаковывайте всю папку; для поиска обоим клиентам нужен свой сервер.

## Быстрый запуск сервера

Установите Git и Docker с поддержкой Compose. В Windows используйте Docker Desktop в режиме Linux containers. Откройте терминал в корне клона:

```powershell
docker compose up -d --build
docker compose ps
```

Проверка в PowerShell:

```powershell
Invoke-RestMethod http://127.0.0.1:3080/api/mvp/health
```

Ожидается `ok: true`, версия `0.7.1`. В браузере на том же ПК доступен адрес `http://127.0.0.1:3080`. Порт по умолчанию привязан к `127.0.0.1`. Настройки аккаунта, `.env`, база PostgreSQL, модели озвучки и резервное копирование для этой версии не нужны.

## Windows

Для сборки из исходников нужны Windows x64, PowerShell и Docker Desktop. Перед первым запуском скачайте закреплённый Electron по инструкции [сборки Windows](docs/SETUP.md#сборка-и-запуск-windows), затем:

```powershell
.\scripts\build-mvp.ps1
.\scripts\run-mvp.ps1
```

Готовая папка приложения: `releases/Gargantua-MVP`. Для переноса нужна вся папка, а не только `Gargantua.exe`.

## Android

Нужен Android 10 или новее. На ПК установите Android Platform Tools и добавьте `adb` в PATH. Разрешите USB-отладку и установку по USB на своём телефоне.

```powershell
.\scripts\build-android-mvp.ps1
adb devices
.\scripts\run-android-mvp.ps1 -Install
```

Скрипт собирает APK, Java-тесты и Android lint; запуск устанавливает приложение и связывает телефон с сервером через USB. APK: `releases/Gargantua-Android/Gargantua-preview.apk`. У него отдельный пакет `local.gargantua.mvp.debug`; сборка не заменяет прежнее приложение с озвучкой.

USB нужен для поиска и новых загрузок в этом режиме. Уже сохранённые главы остаются на телефоне после отсоединения кабеля. APK пока отладочный, с включённой отладкой WebView, без публикации в Google Play. Стабильная ветка не означает подписанную магазинную Android-сборку.

## Android без USB: Tailscale

Установите Tailscale на ПК и телефон, подключите их к своей сети Tailscale. После запуска сервера настройте приватный HTTPS Serve:

```powershell
.\scripts\remote.ps1 enable
.\scripts\run-tailscale-mvp.ps1
```

Скрипт покажет **адрес вашего ПК**. В приложении нажмите настройку сервера и введите этот HTTPS-адрес. Для поиска ПК, Docker и Tailscale должны работать. Публикация через Funnel и открытие портов роутера не нужны. [Подробная настройка и отключение](docs/SETUP.md#подключение-через-tailscale).

## Пользование

1. Найдите книгу или выберите случайную из каталога. Ошибка отдельного источника показывается отдельно от отсутствия результатов.
2. В карточке новеллы нажмите **«Найти продолжение и другие источники»**. Сравните издания, откройте предпросмотр и сохраните объединённую книгу. Объединение добавляет отсутствующие разделы, сохраняя происхождение текста.
3. Нажмите **«Скачать целиком»**. В **«Загрузках»** проверьте число сохранённых разделов. Готовность к чтению без сети означает сохранение всех разделов текущего оглавления.
4. Читайте из библиотеки. Место чтения сохраняется автоматически; в **«Закладках»** можно сохранить место с названием.
5. Для подборки откройте **«Каталоги» → «+»**, затем во **«Всех книгах»** нажмите **«Выбрать» → «В каталог»**. Книга остаётся единственной записью библиотеки. Перестановка доступна отдельным значком списка; под обычными карточками нет панелей управления папками.
6. В Android откройте меню **«…»** нужного каталога, чтобы сохранить или передать файл. Экспорт не скачивает недостающие главы; частичный файл явно показывает число включённых разделов.

Библиотеки ПК и телефона отдельные, автоматической синхронизации нет. Перенос `.gargantua.zip` реализован в Android; импорт ZIP в Windows не заявляется. Android-служба работает при переходе на главный экран телефона; система всё же может остановить её. После принудительной остановки или перезагрузки телефона откройте приложение для продолжения. [Библиотека, фоновые загрузки и перенос каталогов](docs/gargantua/ANDROID_MVP_0_9_GUIDE.md).

## Проверки и отчёты

Проверки 0.9: **151 JavaScript-тест** отдельными командами (123 + 18 + 10), **45 Java-тестов**, Android lint — **0 ошибок / 13 предупреждений**. Настоящий Windows EXE прошёл **52/52** проверки поиска и библиотеки. На физическом Android библиотека прошла **66/66**; её четыре активных файла интерфейса и моста побайтово совпадают с окончательным APK. На окончательном APK отдельно пройден перенос **184/184**: две книги, контрольные суммы всех 183 включённых глав, точное имя вложения, повторный импорт без копий и отказ при повреждении. Открывалось меню отправки с WhatsApp; отправка получателю не выполнялась.

На этом же APK подтверждён прирост сохранённых разделов **53 → 54 из 103** на главном экране телефона до возврата в приложение. Это короткий Home-сценарий, а не гарантия непрерывной работы или проверка выключенного экрана. Автономный перенос **67/67** и импорт в пустое хранилище без сервера **49/49** проверялись отдельно на прежних сборках. Точные SHA и границы каждого сценария — в [отчёте 0.9](docs/gargantua/ANDROID_MVP_0_9_ACCEPTANCE.md).

Полная серия «Коты-воители» не объявляется скачанной: [датированный снимок очереди](docs/gargantua/WARRIORS_DOWNLOAD_STATUS.json) отделяет найденные издания, фактические сохранённые разделы и ещё не представленные позиции библиографии. Счётчик разделов не доказывает полноту иллюстраций или комикса.

Историческая Android-проверка Tailscale версии 0.8 поверх мобильной сети с отключённым USB-маршрутом книжного сервера завершилась **81/81**. Она не выдаётся за новый полный прогон 0.9.

Большой Windows-прогон «Верховного Мага»: **4531 запись оглавления**, **4525 разделов сохранены и открыты офлайн**, **6 закрыты источником**. Полное скачивание 4531/4531 не заявляется. Есть известный сдвиг нумерации между переводами.

[Методика, результаты, ограничения воспроизведения и команды тестов](docs/TESTING.md). Публичные отчёты содержат обезличенные итоги. Сырые журналы, пользовательские профили, тексты книг и персональные сетевые адреса в репозиторий не включаются.
