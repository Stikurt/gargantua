# Гаргантюа — экспериментальная озвучка

Ветка `experimental/audio` сохраняет прежний клиент и сервер с локальной русской озвучкой Piper Denis и экспериментальным переводом EN→RU. Для обычного поиска, скачивания и чтения используйте стабильную ветку `main`: у неё другая серверная архитектура и отдельное приложение Android.

**Это ресурсоёмкая экспериментальная версия.** Синтез, проверка и хранение аудио расходуют процессорное время, оперативную память и диск. Перевод дополнительно использует NVIDIA GPU через Docker. Возможны длительные ожидания ресурсов, паузы и повторный расчёт незавершённого сегмента. Комфортная работа на произвольном компьютере и полная многодневная генерация романа не подтверждены.

| Компонент | Фактически заданное ограничение / наблюдение |
| --- | --- |
| Piper TTS | Контейнер: до 2 ГиБ RAM, 2 CPU, без GPU. Это лимит, а не рекомендация по памяти всего ПК |
| Qwen EN→RU | Контейнер переводчика: до 5 ГиБ RAM, 6 CPU, GPU offload; вспомогательный клиент до 256 МиБ |
| Базовые службы | Отдельно работают PostgreSQL, антивирус ClamAV, обработчик, парсер и HTTP-сервер |
| Аудиофайлы | PCM16 mono 22050 Hz: около 151 МиБ в час, примерно 1,48 ГиБ за 10 часов, без учёта исходников, моделей и Docker |
| Проверка на одном ПК | Piper Denis FP32: около 486 МиБ RSS на коротких отрывках; 15-минутная глава: наблюдённый cgroup peak 612 261 888 байт. Это отдельный пилот, а не обещание скорости любого ПК |

Готовые WAV и позиции прослушивания сохраняются локально; незавершённая задача продолжает с проверенного серверного сегмента. Синтез использует один тяжёлый слот. Состояние `NOT_LISTENED` означает, что качество дикции и приятность голоса на слух не принято. `NOT_FULLY_SCANNED` означает отсутствие полной антивирусной аттестации весов; проверка происхождения, хешей и формата не заменяет её.

Модели, Python wheels, APK/EXE, пользовательские книги, базы, профили, приватные адреса и ключи не входят в Git. Компоненты скачиваются владельцем отдельно по закреплённым источникам и SHA-256. Лицензия исходников проекта не меняет лицензии движков, голосов, моделей, датасетов и книг; условия перечислены в инструкциях установки.

Стабильная и экспериментальная версии не разделяют БД или серверные Docker volumes. Не подменяйте сервер стабильной версии этим сервером при работающем клиенте. Для эксперимента используйте отдельную копию репозитория и остановите стабильный сервер на время занятия порта 3080.
