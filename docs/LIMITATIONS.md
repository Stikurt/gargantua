# Ограничения стабильной версии

Документ относится к исходникам Windows и Android **0.9.0** и серверу **0.7.1**. Готовые файлы предыдущего GitHub Release v0.8.0 содержат прежний клиент; публикация исходников не обновляет их автоматически.

## Сервер и подключения

Поиск, получение оглавления и новых глав выполняются на сервере ПК. Полностью автономный парсер на телефоне не реализован. Без сервера читается уже сохранённый текст.

Windows-клиент использует локальный `http://127.0.0.1:3080`. Android позволяет выбрать сервер через нативный диалог; проверены USB-переадресация и приватный HTTPS Tailscale. Для новых запросов через Tailscale нужны включённые ПК, Docker и Tailscale на обоих устройствах.

Сервер не содержит многопользовательской регистрации и собственной авторизации. По умолчанию порт доступен только локально. Tailscale Serve ограничивается сетью и её правилами доступа; это не инструкция публикации сервера в открытый интернет.

## Источники и объединение

Поддерживаются семь источников, но состав их каталогов, доступность сайтов, переводы и ограничения доступа могут меняться. Ошибка источника и пустая выдача — разные состояния. Найденная книга в одном каталоге не обязательно существует в другом.

Объединение создаёт оглавление со ссылкой на исходный источник каждого раздела. Совпадающие главы сохраняют исходный текст, отсутствующие добавляются; части главы не схлопываются. Неоднозначное сопоставление блокирует автоматическое объединение. Печатные издания с разным разбиением на страницы не склеиваются только по номеру страницы.

Число разделов не равно номеру последней главы: возможны прологи, послесловия и части. Автоматическое сопоставление разных переводов не доказывает непрерывность текста. В проверенном объединении «Верховного Мага» обнаружен сдвиг нумерации преимущественно на пять глав. Шесть ограниченных глав исходного перевода поэтому не подменялись текстами с совпадающими номерами.

Клиент не обходит ограничения доступа и не обещает получить закрытые разделы. Историческая Windows-приёмка «Верховного Мага»: 4531 запись оглавления, 4525 разделов сохранены и проверены офлайн, 6 недоступны. Полная готовность 4531/4531 отсутствует. Отдельный Android-прогон 0.9 проверил 377 фактически сохранённых разделов из оглавления на 4531; эти числа не складываются и не означают полного скачивания на телефоне.

Библиографический список «Котов-воителей» описывает порядок чтения, а не наличие каждого текста у источника. В [датированном снимке](gargantua/WARRIORS_DOWNLOAD_STATUS.json) отдельно указаны выбранные издания и действительно сохранённые разделы; отсутствие выбора на просмотренных страницах не доказывает отсутствие книги во всём интернете. Вся серия из 116 единиц очереди полностью скачанной не объявляется.

## Загрузка и данные

«Скачать целиком» сохраняет текст внутри приложения; экспорт в EPUB, PDF или папку текстовых файлов не реализован. В Android доступен собственный ZIP-формат каталога. Иллюстрации в текущем чтении представлены текстовыми обозначениями: сохранение разделов или карточки комикса не подтверждает полноту его изображений.

Полная офлайн-готовность выставляется после сохранения каждого раздела текущего оглавления. Недоступные главы и ошибки остаются отдельными состояниями. Уже сохранённые разделы не скачиваются повторно при обычном продолжении очереди. После расширения оглавления новые главы требуют новой загрузки.

HTTP 429 вызывает сохранённое ожидание с учётом `Retry-After` и снижение частоты запросов к ограничившему источнику. Длительность скачивания зависит от сайта, связи и устройства; скорость не гарантируется.

В Android очередь обслуживает отдельная foreground-служба с уведомлением; главы фиксируются в устойчивом хранилище до увеличения счётчика. На окончательном APK физически проверена работа на Home. Производитель телефона и Android всё же могут остановить или ограничить службу. После принудительной остановки или перезагрузки откройте приложение; автозапуск при включении телефона не реализован. Полный сценарий выключенного экрана на окончательном APK не подтверждён. Перед отключением связи проверяйте число реально сохранённых разделов.

Библиотеки Windows, телефона и браузера отдельные. Синхронизация между устройствами и облачное резервирование не реализованы. Удаление/очистка данных приложения уничтожает локальную библиотеку; удаление Docker-контейнера само по себе её не удаляет.

Удаление книги через интерфейс убирает её карточку, позицию, закладки и задания этой книги. Кеш исходных глав сохраняется: он может использоваться другим изданием или объединённым оглавлением. Удаление книги не является командой очистки всех сохранённых текстов.

## Локальные каталоги и передача файла

Каталоги содержат ссылки с независимым порядком, а не копии книг. Повторное добавление одной исходной книги не создаёт вторую запись. Разные издания с разными `source/id` остаются разными книгами. Удаление каталога оставляет книги; команда «Убрать отсюда» снимает только одну связь. «Переместить» действует из открытого каталога в выбранный и сохраняет остальные связи.

Сохранение, меню отправки и импорт `.gargantua.zip` реализованы только в Android. Windows-импорт ZIP не реализован. Это ручной снимок: изменившийся каталог не обновляет отправленный файл. Файл содержит описание книг, исходные оглавления, порядок и только уже сохранённые главы; он не скачивает пропуски. Личные закладки, место чтения и адрес сервера в него не входят.

Импорт локального файла с включёнными главами работает без сервера. Облачный файловый провайдер сначала может потребовать сеть для получения самого файла. Повторный импорт может создать ещё один каталог-ссылку, сохранив единственные книжные записи. Старое оглавление дополняется только при точном совпадении его начала; несовместимое не заменяется. Другой текст того же исходного ключа вызывает отказ `CATALOG_CONFLICT`, прежний текст не перезаписывается.

Нативные главы импортируются атомарно после проверки, а книжные карточки и каталог создаются затем в отдельном хранилище интерфейса. Это не общая транзакция двух хранилищ. Пределы одного файла: **1000 книг, 50 000 разделов, 8 МиБ описания, 24 МиБ на раздел, 512 МиБ ZIP и 1 ГиБ распакованных данных**. Требуется место под временные файлы.

На окончательном APK проверены сохранение, точное имя вложения в Android chooser, содержимое ZIP и повторный импорт. Реальная доставка получателю не выполнялась; runtime-флаги разрешения чтения URI Android не раскрыл, эта проверка отмечена пропущенной. Строгий офлайн и импорт в пустое хранилище проверены отдельно на прежних сборках; [происхождение доказательств](gargantua/ANDROID_MVP_0_9_ACCEPTANCE.md) указано явно.

## Сборка и поддерживаемые платформы

Windows-приложение собирается для x64. Сборка и запуск сценариев проверялись в Windows PowerShell 5.1. Сервер работает в Linux-контейнере Docker. Отдельная приёмка клиента Linux, macOS и iOS не проводилась.

Android требует API 29 / Android 10 или новее. Проверено одно физическое устройство на Android 15, включая клавиатуру и поворот экрана. Это не матрица совместимости всех производителей и версий WebView.

Публикуемая Android-сборка отладочная, пакет `local.gargantua.mvp.debug`, WebView debugging включён. Google Play, подпись релизным магазинным ключом и автоматические обновления не настроены. Для установки обновления с сохранением данных требуется тот же ключ подписи.
