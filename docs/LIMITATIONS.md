# Ограничения стабильной версии

## Сервер и подключения

Поиск, получение оглавления и новых глав выполняются на сервере ПК. Полностью автономный парсер на телефоне не реализован. Без сервера читается уже сохранённый текст.

Windows-клиент использует локальный `http://127.0.0.1:3080`. Android позволяет выбрать сервер через нативный диалог; проверены USB-переадресация и приватный HTTPS Tailscale. Для новых запросов через Tailscale нужны включённые ПК, Docker и Tailscale на обоих устройствах.

Сервер не содержит многопользовательской регистрации и собственной авторизации. По умолчанию порт доступен только локально. Tailscale Serve ограничивается сетью и её правилами доступа; это не инструкция публикации сервера в открытый интернет.

## Каталоги и объединение

Поддерживаются семь источников, но состав их каталогов, доступность сайтов, переводы и ограничения доступа могут меняться. Ошибка источника и пустая выдача — разные состояния. Найденная книга в одном каталоге не обязательно существует в другом.

Объединение создаёт оглавление со ссылкой на исходный источник каждого раздела. Совпадающие главы сохраняют исходный текст, отсутствующие добавляются; части главы не схлопываются. Неоднозначное сопоставление блокирует автоматическое объединение. Печатные издания с разным разбиением на страницы не склеиваются только по номеру страницы.

Число разделов не равно номеру последней главы: возможны прологи, послесловия и части. Автоматическое сопоставление разных переводов не доказывает непрерывность текста. В проверенном объединении «Верховного Мага» обнаружен сдвиг нумерации преимущественно на пять глав. Шесть ограниченных глав исходного перевода поэтому не подменялись текстами с совпадающими номерами.

Клиент не обходит ограничения доступа и не обещает получить закрытые разделы. Приёмка «Верховного Мага»: 4531 запись оглавления, 4525 разделов сохранены и проверены офлайн, 6 недоступны. Полная готовность 4531/4531 отсутствует. Эта большая проверка выполнена только на Windows.

## Загрузка и данные

«Скачать целиком» сохраняет текст внутри приложения; экспорт в EPUB, PDF или папку текстовых файлов не реализован. Иллюстрации в текущем чтении представлены текстовыми обозначениями.

Полная офлайн-готовность выставляется после сохранения каждого раздела текущего оглавления. Недоступные главы и ошибки остаются отдельными состояниями. Уже сохранённые разделы не скачиваются повторно при обычном продолжении очереди. После расширения оглавления новые главы требуют новой загрузки.

HTTP 429 вызывает сохранённое ожидание с учётом `Retry-After` и снижение частоты запросов к ограничившему источнику. Длительность скачивания зависит от сайта, связи и устройства; скорость не гарантируется.

Android может остановить приложение в фоне. Очередь сохраняется и продолжается после открытия, но непрерывное скачивание при закрытом приложении не обещается. Перед отключением связи проверяйте число реально сохранённых разделов.

Библиотеки Windows, телефона и браузера отдельные. Синхронизация между устройствами и облачное резервирование не реализованы. Удаление/очистка данных приложения уничтожает локальную библиотеку; удаление Docker-контейнера само по себе её не удаляет.

## Сборка и поддерживаемые платформы

Windows-приложение собирается для x64. Сборка и запуск сценариев проверялись в Windows PowerShell 5.1. Сервер работает в Linux-контейнере Docker. Отдельная приёмка клиента Linux, macOS и iOS не проводилась.

Android требует API 29 / Android 10 или новее. Проверено одно физическое устройство на Android 15, включая клавиатуру и поворот экрана. Это не матрица совместимости всех производителей и версий WebView.

Публикуемая Android-сборка отладочная, пакет `local.gargantua.mvp.debug`, WebView debugging включён. Google Play, подпись релизным магазинным ключом и автоматические обновления не настроены. Для установки обновления с сохранением данных требуется тот же ключ подписи.
