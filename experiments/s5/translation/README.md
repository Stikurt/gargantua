# Архив инструментов пилотного перевода

Здесь сохранён исходный код сравнительных экспериментов с локальными EN→RU-моделями, ограниченным контекстом, checkpoint и проверкой завершения. Это исследовательские инструменты; серверный выбранный профиль хранится отдельно в `inference/profiles.lock.json` от корня репозитория.

Для новой установки используйте [основную инструкцию экспериментальной ветки](../../../SETUP_AUDIO.md), а для опубликованных результатов и ограничений — [сводку проверки](../../../TESTING_AUDIO.md). Пилотные команды с локальными историческими ID, уже завершёнными checkpoint или неопубликованными эталонами не являются универсальной установкой из свежего клона.

Исходные корпуса `corpus.json`, `../chapter-inputs.json` и `../holdout-inputs.json` написаны специально для проекта, а не взяты из пользовательских книг. Приватные русские эталоны и сырые модельные результаты в репозиторий не входят. Поэтому историческая проверка хеша приватного эталона в `test_run_gpu.py` и отдельные review-скрипты без этих локальных данных не повторяются. Они не входят в список обязательной опубликованной приёмки.

Публичные манифесты моделей фиксируют происхождение, ревизии, размеры, SHA-256 и отдельные лицензии. Для дополнительного анализа сохранены базовые модели OPUS, M2M100 и Qwen; их наличие в манифесте не означает включение всех моделей в сервер или поставку весов в Git. Выбранный серверный перевод использует отдельный Qwen3.5 4B Q4 профиль. Runtime/веса скачиваются владельцем отдельно; сетевой доступ во время генерации отключён.

Перевод остаётся машинным черновиком. Техническая целостность, сохранение сегментов и успешное завершение не заменяют проверку смысла, имён и литературного качества. CPU/GPU, RAM и диск ограничиваются отдельно; запускать дополнительные пилоты одновременно с серверной тяжёлой работой не следует. Полная генерация романа и произвольная новая GPU этим архивом не приняты.
